# Week 4: Excel Text and Date Functions

## Overview

This repository documents my **Week 4 learning progress** in my Data Analytics journey. This week, I focused on Excel Text Functions and Date Functions, which are essential for cleaning, transforming, standardizing, and managing datasets.

## Topics Covered

### 1. Text Functions

| Function | Purpose |
|---|---|
| `LEFT()` | Extracts characters from the beginning of a text string. |
| `RIGHT()` | Extracts characters from the end of a text string. |
| `MID()` | Extracts characters from a specified position in a text string. |
| `LEN()` | Returns the number of characters in a text string. |
| `TRIM()` | Removes extra spaces from text. |
| `PROPER()` | Capitalizes the first letter of each word. |
| `UPPER()` | Converts text to uppercase. |
| `LOWER()` | Converts text to lowercase. |
| `CONCAT()` | Combines text from multiple cells or strings. |

### 2. Date Functions

| Function | Purpose |
|---|---|
| `TODAY()` | Returns the current date. |
| `NOW()` | Returns the current date and time. |
| `DATE()` | Creates a date using year, month, and day values. |
| `DAY()` | Extracts the day from a date. |
| `MONTH()` | Extracts the month from a date. |
| `YEAR()` | Extracts the year from a date. |
| `WORKDAY()` | Calculates a date a specified number of working days before or after a start date. |
| `NETWORKDAYS()` | Counts the working days between two dates. |

## Practical Applications

During this week, I practised using Excel functions to:

- Clean and standardize names in a dataset.
- Extract specific characters from text values.
- Remove unnecessary spaces from text.
- Convert names into consistent letter cases.
- Combine first and last names into full names.
- Extract day, month, and year components from dates.
- Calculate working days between dates.
- Determine future or previous working dates.
