# Week 6: Sales Analysis Dashboard Using Microsoft Excel

## Project Overview

As part of Week 6 of my Data Analytics learning journey, I worked on creating an interactive sales dashboard using Microsoft Excel.

This project marked the completion of my Excel learning journey. I applied what I had learned about Pivot Tables and data visualization to organize sales information and present it in a visual dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization

## What I Did
- Worked with a sales dataset.
- Created Pivot Tables to summarize and analyze sales data.
- Analyzed revenue by sales representative.
- Examined revenue by payment method.
- Analyzed sales across different customer types and regions.
- Created charts to visualize the results.
- Designed a sales dashboard to present the insights in an organized and understandable format.

## Key Learning Outcomes

Through this project, I gained practical experience in:
- Creating and working with Pivot Tables.
- Summarizing large amounts of data.
- Understanding how to use charts to communicate insights.
- Designing dashboards for data presentation.
- Turning raw sales information into meaningful insights.

## Project Reflection

This project has been a valuable part of my learning experience. It helped me understand how Excel can be used not only to organize data but also to analyze and communicate information effectively.

Completing this project also marks the end of my Excel learning journey.
