# My First 6 Weeks of Data Analytics Journey 📊

## From Learning Excel to Building My First Dashboard!

Six weeks ago, I started my Data Analytics learning journey with the goal of developing practical skills and understanding how data can be transformed into meaningful insights.

Looking back, I'm excited about how much I've learned and the progress I've made.

### My Learning Progress

**Week 1 – Getting Started with Data Analytics**
- Began my journey into data analytics.
- Started learning the fundamentals of working with data and Microsoft Excel.

**Week 2 – Data Cleaning and Preparation**
- Learned the importance of cleaning raw data before analysis.
- Practiced identifying and correcting inconsistencies in a sales dataset.
- Prepared data for further analysis.

**Week 3 – Excel Functions and Logical Operations**
- Practiced Excel functions such as SUMIF, AVERAGE, AVERAGEIF and COUNT.
- Learned about logical operations, including AND, OR, NOR and NAND.

**Week 4 – Practical Excel Learning**
- Continued developing my Excel skills through practical exercises and hands-on learning.

**Week 5 – Building My Excel Skills**
- Continued practicing and strengthening my understanding of Excel and data analysis.

**Week 6 – Pivot Tables and Dashboard Creation**
- Learned how to create and work with Pivot Tables.
- Summarized and analyzed sales data.
- Created charts and designed a sales dashboard.
- Learned how to present data in a more visual and understandable way.

### Key Takeaways

These six weeks have taught me that data analytics goes beyond working with numbers. It involves asking questions, preparing data, identifying patterns, analyzing information and communicating insights effectively.

I've also learned the importance of consistency, practice and being open to learning new things.

### What's Next?

I'm excited to announce that I've completed my Excel learning journey and I'm now moving on to **Microsoft Power BI**!

I'm looking forward to exploring new tools, building more projects and continuing to grow as an aspiring Data Analyst.

This is only the beginning. One step at a time! 🚀

Thank you for following my journey.
